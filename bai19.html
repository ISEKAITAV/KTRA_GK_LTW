Bài tập 19: Deploy lên GitHub Pages

Portfolio 3 trang kèm ảnh chân dung

Đề bài

Tạo website portfolio 3 trang (index.html, about.html, contact.html) kèm CSS, JavaScript và ảnh chân dung cá nhân. Tạo repo my-portfolio trên GitHub, push code, bật Settings → Pages (branch main, thư mục root) và nộp link GitHub Pages.

Kết quả

  • Repo GitHub (public): https://github.com/ISEKAITAV/my-portfolio
  • GitHub Pages: https://isekaitav.github.io/my-portfolio/
